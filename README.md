# lovox
Lovox — российская система управления задачами, проектами и базой знаний компании. Объединяет Kanban, корпоративную Wiki, регламенты, обучение сотрудников, запись и транскрибацию встреч, AI-ассистента, AI-агентов и автоматизации. Аналог Notion, Confluence, ClickUp и Trello для команд и бизнеса.
